# Foundation / Search Launch Checklist

Track evidence in the Site 17 Notion work page and Site Control Page. A local build does not prove Production, browser behavior, search-engine ownership or indexing.

## Site foundation

- [x] Distinct smart-home topic and useful Korean homepage
- [x] Navigation, About, Privacy, Contact and Editorial Policy
- [x] Canonical and minimum title/description/social metadata
- [x] Static `robots.txt`, XML sitemap, custom 404 and IndexNow key file
- [x] Local Astro check, build and generated-output tests (4/4)
- [ ] Cloudflare Pages Production deployment and custom domain verified
- [ ] Desktop and mobile Production browser QA
- [ ] Actual unknown-route response verified as a 404 in Production
- [ ] Minimum Indexability Gate documented with evidence
- [ ] Remove `noindex` only after the minimum gate passes

## Search providers

- [ ] Google Search Console property ownership registered
- [ ] Google sitemap submitted and provider receipt/status recorded
- [ ] Naver Search Advisor site registered
- [ ] Naver sitemap submitted and provider receipt/status recorded
- [ ] IndexNow key file reachable in Production
- [ ] IndexNow submission sent to the official endpoint and response recorded
- [ ] Daum Search Advisor registration/status checked where available
- [ ] Site Registry and Site Control synchronized from current evidence

Search ownership, sitemap acceptance, crawling, indexing and ranking are distinct states. Login, 2FA, CAPTCHA, account approval or applicant-consent requirements are provider-specific blockers; record them and continue other independent sites.

Central Review may remain pending after this site's foundation evidence is complete and must not stop the next independent site.
